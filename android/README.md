# Studio Nails & Beauty — Android

Aplicación nativa en Kotlin y Jetpack Compose. Misma libreta que la versión web: manicura y clienta, sin cuentas.

Abre esta carpeta en Android Studio y usa **Build → Build APK(s)**.

- Paquete: `com.studionails.beauty`
- Mínimo: Android 8
- Los datos quedan en el teléfono
- La cámara se usa para leer el QR de la billetera. Si no abre, se escribe el código de seis letras
- Los recordatorios piden permiso de notificaciones
